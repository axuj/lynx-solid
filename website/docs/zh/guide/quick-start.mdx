# 快速开始

欢迎使用 Lynx Solid！我们创建一个 Solid Lynx 项目并开始开发。

## 系统要求

- [Node.js 18](https://nodejs.org/en) 或更高版本。
  - 使用 TypeScript 作为配置时需要 Node.js 18.19。

## 开始开发

开始使用 Lynx Solid 最快的方式是只搭建前端项目，然后用 **Lynx Explorer**（原生预览）或 **Lynx for Web**（浏览器预览）来查看效果。

### 创建新的 Lynx Solid 项目

每个 Lynx Solid 应用都从三个文件起步——`package.json`、`rsbuild.config.ts`、`src/index.tsx`：

```json title="package.json"
{
  "name": "my-lynx-solid-app",
  "type": "module",
  "private": true,
  "scripts": {
    "dev": "rsbuild dev",
    "build": "rsbuild build"
  },
  "dependencies": {
    "@lynx-solid/runtime": "^0.1.0",
    "solid-js": "^2.0.0-rc.18"
  },
  "devDependencies": {
    "@lynx-js/rsbuild-plugin": "^0.1.6",
    "@lynx-js/types": "^4.3.0",
    "@lynx-solid/plugin": "^0.1.0",
    "@rsbuild/core": "^2.2.14",
    "typescript": "^5.5.0"
  }
}
```

`@lynx-solid/plugin` 会带上 `@lynx-solid/compiler`，三个 `@lynx-solid/*` 包始终同版本发布。`solid-js` 是 runtime 的 peer 依赖——请保证应用里只有一份。

```ts title="rsbuild.config.ts"
import { defineConfig } from '@rsbuild/core'
import { pluginSolidLynx } from '@lynx-solid/plugin'

export default defineConfig({
  environments: {
    lynx: {},
    web: {},
  },
  source: {
    entry: {
      main: './src/index.tsx',
    },
  },
  plugins: [pluginSolidLynx()],
})
```

```tsx title="src/index.tsx"
import { createSignal } from 'solid-js'
import { render } from '@lynx-solid/runtime'

function Counter() {
  const [count, setCount] = createSignal(0)

  return (
    <view style="display:linear;linear-direction:column;align-items:center;padding:48px">
      <text style="font-size:28px">
        count:
        {count()}
      </text>
      <view
        bindtap={() => setCount(c => c + 1)}
        style="margin-top:24px;padding:12px 32px;background-color:#2c4f7c;border-radius:8px"
      >
        <text style="color:#ffffff;font-size:20px">increment</text>
      </view>
    </view>
  )
}

render(() => <Counter />)
```

TypeScript 需要把 Solid JSX 映射到 Lynx 内建元素（`jsxImportSource`，`jsx: preserve` 让插件编译器消费 JSX——见 [TypeScript](/zh/guide/typescript)）。

### 运行开发服务器

1. 安装依赖：

<PackageManagerTabs command="install" />

2. 启动开发服务器：

<PackageManagerTabs command="run dev" />

你应该会看到类似这样的输出：

```
Rsbuild v2.2.9

  ➜  Lynx       http://localhost:3000/main.lynx.bundle
  ➜  Web        http://localhost:3000/main.web.bundle
  ➜  ∟ Preview  http://localhost:3000/__web_preview?casename=main.web.bundle
```

开发服务器会生成三个 URL：

- **Web Preview** — 在浏览器中打开此链接可快速预览你的应用。
- **Lynx** — 用于通过 Lynx Explorer 进行原生渲染的 bundle URL（见下一步）。
- **Web** — 原始 Web bundle（适用于集成到 Web 容器中）。

### 在 Web 上预览

在浏览器中打开 **Web Preview** URL。你将看到应用在 Web 上渲染的实时预览，编辑代码时会自动更新。

### 在原生设备上预览

要查看应用的原生渲染效果，请把上面预览切到**二维码**页，用 **Lynx Explorer** 扫码；或复制终端里的 **Lynx** bundle URL，粘贴到 Lynx Explorer 的 "Enter Card URL" 中。

需要安装？iOS 模拟器包、Android APK 和源码构建方式以官方文档为准：**[下载 Lynx Explorer](https://lynxjs.org/zh/guide/start/quick-start.html#download-lynx-explorer)**。

- **iOS**：把解压出来的 `.app` **拖进模拟器窗口**；双击会装到你自己的 Mac 上。
- **Android**：安装 APK 时给浏览器或文件管理器开"允许安装未知来源应用"。

## 部署到生产环境

你创建的 Lynx Solid 项目是一个**前端**项目 — 它生成 JavaScript bundle，由支持 Lynx 的原生应用加载和渲染。Lynx Explorer 是一个用于开发的预构建原生应用，但在生产环境中你需要自己的原生应用。

### 使用 Sparkling（实验性）

[Sparkling](https://tiktok.github.io/sparkling) 是 TikTok 开源的 Lynx 应用构建基础设施。提供 CLI 工具，可在数分钟内搭建带有 scheme 驱动导航的原生应用项目。目前为**实验性**，仅支持 **iOS 和 Android**。

### 集成到现有应用

如果需要最大的灵活性，可以将 Lynx 直接集成到你的现有应用中。支持 **iOS、Android、Harmony、桌面端和 Web**，让你完全控制 Lynx 在应用中的嵌入方式。

按照 [Lynx 集成指南](https://lynxjs.org/guide/start/integrate-with-existing-apps) 开始集成。
